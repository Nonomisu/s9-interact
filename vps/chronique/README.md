# Chronique de la semaine de S9 Interact' (`s9-chronique`)

Chaque dimanche à 20 h, un résumé de la semaine part sur le salon Discord commun : journées racontées, activités communes,
événements, anniversaires, Flash Actu et Wondereye. Jamais rien des espaces des couples ni de Pixel Meet.
N'écrit dans la base que `shared/chronique` (semaine déjà envoyée). Entre deux dimanches, « stopped » dans `pm2 list` : c'est normal.
Aperçu sans envoi : `DST_KEY=~/secrets/s9-interact-cle.json node chronique.js --apercu`.

Installation : voir `vps/README.md`. Test sans réseau : `node test-chronique.js`.
